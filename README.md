# Radio Shelf v1.2

ぶいすぽっ！ファンクラブの**公式ラジオ個別ページを整理する個人用・非公式Webアプリ**です。音声や画像の収集・再配信・ダウンロード、会員認証の自動化は行いません。

## 機能

- 公式URLを登録、検索、タイトル・出演者・公開日・メモを編集
- 公式ページからコピーした複数のURLを貼り付けて、過去回を一括追加（重複除外）
- お気に入り／視聴済み（手動）／未視聴の絞り込み
- 「公式で聴く」からSafariの公式個別ページを開く。バックグラウンド再生・ロック画面操作は公式サイトの挙動に依存
- 公式のお知らせ文を貼るとURL、回数、日付を可能な範囲で抽出
- カタログ同期: 起動時／再表示時／30分ごと／手動で `catalog.json` を確認
- JSONバックアップ／復元
- iPhone「ホーム画面に追加」対応のPWA
- 他のアプリから `https://<公開したアプリURL>/?add=<URLエンコードした公式URL>` で追加画面を開ける

## 重要な制約

- **公式サイトを自動巡回して新着のURLを見つける機能は、現段階では未実装。** サイトの会員領域を解析・取得せず、`catalog.json` に収録されたデータだけを同期する。
- 初期カタログの4件は公式ニュースの公開URLから確認したもの。全話を網羅するものではない。
- `catalog.json` の更新は管理者の作業、または今後用意する適法な外部公開フィードが必要。カタログ未更新なら新着は現れない。
- 個人データは各端末の `localStorage` 保存。端末間同期なし。ブラウザデータ削除で消えることがあるのでJSONバックアップ推奨。
- アプリのシェルだけオフライン表示可能。公式ラジオはインターネット接続・会員ログインが必須。
- 再生画面は**外部の公式サイト**で開く。自作アプリ内にプレーヤーを埋め込むものではない。
- このアプリはぶいすぽっ！および運営会社の公式・公認アプリではない。

## ローカルで動作確認する

1. ファイルを任意のフォルダに展開する。
2. フォルダ内で `python -m http.server 8000` を実行する（Pythonがある場合）。
3. ブラウザで `http://localhost:8000` にアクセスする。
4. `node --test tests/*.test.js` でロジックテスト可能。

## GitHub Pagesで公開する

1. リポジトリ `mikisaa/vspo-radio-shelf` は作成済み・Publicです。アプリのファイルは `main` の直下に配置済みです。
2. アプリの更新時は `main` に変更をコミットします。
3. GitHub の **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を設定する。リポジトリへのコード登録だけでは、Pages公開は有効になりません。
4. 公開されたら URL `https://mikisaa.github.io/vspo-radio-shelf/` をSafariで開く（設定が完了するまでこのURLは使えない）。
5. Safariの共有ボタン → **ホーム画面に追加**。公開後、ログイン済みの公式ページに各回のリンクから移動できます。

> GitHub Pages上のHTML/CSS/JSと `catalog.json` は公開されます。パスワード・Cookie・会員向け音声・個人メモは絶対にコミットしないでください。メモ・お気に入り状態は公開されず端末内にあります。

## 更新の仕組み

`catalog.json` の `items` に公式のラジオURL・タイトル・日付を追加してpushすると、次回アプリ起動時などに端末が取得し、自動的にライブラリに追加します。重複回は `radio番号` で判定します。ユーザーのお気に入り・視聴済み・メモは保持します。

```json
{
  "version": "2026-11-16-initial",
  "items": [
    {"url": "https://fc.vspo.jp/gallery/radio99", "title": "第56回ラジオ", "date": "2026-07-02", "hosts": "", "notes": ""}
  ]
}
```

バージョンやファイル名に機密データは含めないでください。

## 運用上の注意

公式規約にはシステム解析やコンテンツの無断転載を制限する条項があります。スクレイピング・会員ページへの自動ログイン・音声ファイル収集は本ツールでは実施しません。公式の通知メールなど、正当に得た更新情報からの登録を将来検討します。

## 過去回の追加と公式の制限

- 初期登録されている過去回は、**公式の公開告知で個別URL・回数・公開日を確認できた4件のみ**です。`radio番号` と番組の `第○回` は一致しないため、未確認のURLや回数を連番から生成しません。
- 追加するには公式サイトで閲覧できる各ラジオのURLをコピー → アプリの「過去回をまとめて追加」に貼り付けます。公式の一覧画面は会員ログインが必要なため、このツール単独では一括収集できません。
- 公式FAQの「ファンクラブ加入した月より前のコンテンツは視聴・ダウンロード可能でしょうか」によると、**加入月より前に更新されたコンテンツは視聴・ダウンロードの対象外**です。URLを登録しても視聴できるとは限りません。 https://fc.vspo.jp/faq
- GitHub Pagesの公開はリポジトリの作成とPages有効化が必要です。ZIP自体は公開作業を実施したものではありません。
